# AI Assistant для STE Slicer

Плагин добавляет в STE Slicer (форк Cura 3.6) чат-ассистента на базе LLM. Пользователь описывает задачу печати текстом, прикладывает фото (JPG/PNG) или модели (STL/OBJ/3MF), а агент через MCP-инструменты выбирает режим 3D/5D, профиль, материал и настройки, ставит модель на стол, запускает слайсинг и объясняет свои решения.

## Требования

- STE Slicer 7.10.x для Windows (проверено на 7.10.12), машина Stereotech Hybrid 530 V5.2.4.
- Для режимов 5D (`cylindrical`, `cylindrical_full`) нужна активированная лицензия ATSS.
- Доступ к OpenAI-совместимому API (Chat Completions с tool calling): URL, ключ и имя модели.
- Внешних зависимостей нет: только стандартная библиотека Python 3.5 и PyQt5 из дистрибутива.

## Установка

1. В STE Slicer откройте **Справка → Показать папку конфигурации** (обычно `%APPDATA%\steslicer\7.x\`).
2. Скопируйте папку `AIAssistant` целиком в подпапку `plugins` (создайте её, если её нет). Получится `...\steslicer\7.x\plugins\AIAssistant\plugin.json`.
3. Перезапустите слайсер. У правого края окна появится синий язычок **AI Assistant**, в главном меню — **Расширения (Extensions) → AI Assistant** с пунктами *Open chat*, *Settings* и *User guide (PDF)*.

Подробное руководство пользователя с описанием всех инструментов: [docs/AI_Assistant_user_guide_ru.pdf](docs/AI_Assistant_user_guide_ru.pdf) (кнопка «?» в панели).

## Настройка доступа к LLM

1. Шестерёнка в заголовке панели или **Расширения → AI Assistant → Settings**: откроются настройки прямо в панели слайсера.
2. Введите **Base URL** (например `https://api.timeweb.ai/v1`), **API key** и **модель**, нажмите «Проверить подключение», затем «Сохранить».
3. Ключ хранится в настройках приложения (`preferences.cfg` в папке конфигурации, группа `ai_assistant`). В исходниках плагина его нет, в интерфейсе он показывается маскированным.

Дополнительные параметры (температура, лимит шагов агента, таймаут, повторы, размер изображений, порт, флажки) меняются там же.

## Использование

1. Чат встроен в главное окно слайсера: синий язычок «AI Assistant» у правого края (или **Расширения → AI Assistant → Open chat**) раскрывает панель, 3D-вид сдвигается влево; левый край панели тянется мышью. Пока курсор над панелью, мышь не управляет сценой.
2. Опишите задачу и прикрепите файлы. Пример: «Кронштейн под нагрузку, PETG, без поддержек» + STL.
3. В чате видно каждый вызов инструмента и его результат, прогресс слайсинга и итог: время печати и расход материала.
4. Поддержки другим материалом (например растворимый PVA вторым экструдером) ассистент настраивает в 3D, если попросить об этом прямо.
5. Попросите сохранить проект (3MF) и G-code или сохраните их из меню слайсера.

## Выбор режима по прочности

Если в ТЗ есть нагрузка (изгиб, кручение, обороты, давление, зуб, обод), агент вызывает `compare_print_strategies` и выбирает 3D или 5D по расчёту, а не по описанию. FDM-деталь анизотропна: вдоль слоя прочность X = 1, поперёк слоёв (по нормали n) Z = k_z, межслойный сдвиг S = k_s. Для напряжения вдоль направления d (sin θ = |d·n|) прочность по Цаю–Хиллу:

    1/s(θ)² = cos⁴θ/X² + (1/S² − 1/X²)·cos²θ·sin²θ + sin⁴θ/Z²

Нормаль слоя: 3D — вектор «вверх» позы; 5D и 5D Spiral — радиальная r(φ) (цилиндрические слои); сердечник Ø6 в 5D — ось (отдельная строка). Индекс — среднее по 36 точкам окружности (для зуба и обода — худшая четверть), итог — средневзвешенный по нагрузкам. Разница ≥ 0.15 — решает прочность, иначе геометрия (поддержки, свесы); при 0.08–0.15 и проигрыше по прочности ответ называет цену компромисса. Все числа — **[оценка]** по типичным данным анизотропии FDM, не измерения.

| Класс материала | k_z | k_s |
|---|---|---|
| PLA / PETG / ABS / ASA / PC (по умолчанию) | 0.55 | 0.60 |
| наполненные волокном (CF/GF) | 0.45 | 0.50 |
| TPU / эластомеры | 0.80 | 0.80 |

Нагрузки: `shaft_bending`, `torsion`, `axial_tension`, `centrifugal`, `hoop_pressure`, `radial_load`, `gear_tooth`, `custom` (свой `direction` в осях файла); у каждой свой `weight`. Для тела без оси вращения 5D «неприменимо», считаются только `custom` и `axial_tension` с `direction`. Код: `agent/geometry/strength.py`, `agent/tools/strength_tools.py`.

## MCP-сервер

Те же инструменты, что получает LLM, доступны внешним MCP-клиентам: JSON-RPC 2.0 по HTTP, `POST http://127.0.0.1:<порт>/mcp` (порт по умолчанию 8765, занят — берётся свободный) (`initialize`, `tools/list`, `tools/call`, `ping`). Сервер слушает только localhost.

Полный список инструментов с параметрами — в разделе 12 руководства [docs/AI_Assistant_user_guide_ru.pdf](docs/AI_Assistant_user_guide_ru.pdf).

## Отладка

- Логи плагина пишутся в общий лог слайсера (`stderr.log` и `*.log` в папке конфигурации) с префиксом `[AIAssistant]`.
- Чтобы разрабатывать без слайсера, есть стенд с моками сцены (папка `devtools` в корне репозитория): `python devtools/run_standalone.py` даёт тот же API и MCP. Смоук-тест MCP: `python devtools/mcp_smoke_test.py`.
- Руководство пересобирается из кода (справочник инструментов — из реестра): `python devtools/build_manual.py`.
