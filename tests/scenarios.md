# Тестовые сценарии агента

Запросы по 7 моделям кейса для ручного прогона в слайсере или полуавтоматического — `devtools/live_run.py`.
Принтер: Stereotech Hybrid 530 V5.2.4, сопло 0.4. Перед каждым сценарием: новый диалог, пустая сцена, профиль по умолчанию.

Откуда ожидания: ТЗ из `models/` (текст всех ТЗ — `models/_TZ_all.txt`) и база знаний `agent/knowledge/*`
(детерминированные ответы `recommend_material` и `get_print_preset`). Официального эталона нет: «ожидаемое решение» —
наше инженерное прочтение ТЗ, оно совпадает с `devtools/targets/*.json`. Детерминированная часть (что LLM должна
вычитать из ТЗ → recommend_material / get_print_preset → поправки шага 6) зашита в `devtools/pipeline_dryrun.py`
(`TZ_EXTRACT`) и проверяется `tests/test_knowledge_tools.py`.

Строка «цепочка» — минимальный ожидаемый порядок вызовов; лишние чтения (`get_current_config`, `get_settings`,
`list_objects`) допустимы.

Общие критерии прохождения (для всех 7 моделей):
- режим выставлен ДО материала и профиля; `set_settings` — один-два вызова, только точные ключи;
- материал из `list_materials`, id совпадает с ожидаемым или с допустимой альтернативой;
- в 5D: ось вращения вертикально, центр оси в (0, 0) ±0.5 мм, `adhesion_type`/стол не трогались;
- слайсинг завершён, время и масса в карточке взяты из `get_slicing_result`;
- итоговая карточка: таблица параметров + «Почему так» + «Выполнимость ТЗ» + «Оговорки» (паспорт филамента, калибровка);
- нет выдуманных ключей и повторов одного вызова; ≤ 15 вызовов на запрос.

## 1. Шестерня (папка «3D»)

**Пользователь:** «Ведущая шестерня привода натяжения троса в оранжерее. Влажность до 98 %, до +70 °C, прямое солнце, подкормки (слабые кислоты). Пиковый момент 75 Н·м, нужен жёсткий материал с Tg не ниже 85–90 °C. Подготовь к печати.» + `Шестерня.stl` (+ опционально `Шестерня.jpg`).

**Цепочка:** load_model → analyze_model → set_print_mode(classic) → recommend_material(needs=[moisture, stiffness, uv, acid, toughness], service_temp_c=70, min_tg_c=85, kind=rigid) → list_materials("ABSPA") → set_material(fiberpart_abspa_g8) → get_print_preset([functional_load, precise_fit], classic, fiberpart_abspa_g8) → select_profile(normal) → set_settings → suggest_orientation / rotate_object → start_slicing → get_slicing_result.

**Ожидаемое решение:**
| Параметр | Значение |
|---|---|
| Режим | `classic` (3D): плоский диск 33×10 мм, зуб формируют периметры в XY; 5D не даёт выигрыша |
| Материал | `fiberpart_abspa_g8` (первый в рейтинге: УФ-стойкий по данным производителя, ударопрочный, Tg ~100) или `fiberpart_pc_g20` (жёстче, Tg ~145, но желтеет на УФ) — оба в цели; ASA в библиотеке H530 нет |
| Профиль | `normal` (0.1 мм) — точность эвольвенты |
| Настройки | `wall_line_count` 4, `top_bottom_thickness` 1.2, `infill_sparse_density` 100 (деталь 3.8 см³ < 20 см³), `infill_pattern` gyroid, `speed_print` 40, `speed_wall_0` 20, `outer_inset_first` true, `z_seam_type` back, `adhesion_type` brim, `brim_width` 5, `support_enable` false |
| Температуры | из профиля: ABSPA G8 280 / 115 °C (PC G20 290 / 115), обдув 0 |
| Ориентация | диск на столе, ступица вверх (ось Y файла → Z, +90° вокруг X), центр стола |
**Честность:** ABSPA G8 — PA-составляющая впитывает влагу (гидрофобность «с оговорками», размеры зуба во влажности — проверить); PC G20 желтеет на УФ (покрытие/окраска); 75 Н·м на детали Ø33 мм с модулем ~0.8 — нагрузка явно выше возможностей FDM-зуба такого размера, нужны испытания; в модели нет отверстия под стопорный винт — настраиваем по модели; абразив → закалённое сопло, T +15–30 °C уточнить по паспорту.

## 2. Колесо конвейерной линии (папка «5D»)

**Пользователь:** «Ведущее колесо конвейера для пачек бумаги, 24/7, 450 об/мин, нагрузка до 18 кг. Не должно пачкать и пылить, протирка изопропиловым спиртом, нужна хорошая сцепляемость с бумагой. Отверстие под вал — точно, ±0.1. Печатаем в 5D.» + `Колесо.STL`.

**Цепочка:** load_model → analyze_model → set_print_mode(cylindrical) → recommend_material(needs=[grip, clean, toughness, wear], service_temp_c=22) → set_material(enduse_tpu_d70) → get_print_preset([rotation_5d, precise_fit], cylindrical, enduse_tpu_d70, base_diameter=16) → select_profile(fast) → set_settings → suggest_orientation (ось Y → Z, центр в 0,0) → start_slicing → get_slicing_result.

**Ожидаемое решение:**
| Параметр | Значение |
|---|---|
| Режим | `cylindrical` (5D Spiral) на оправке Ø16 = сквозное отверстие (по analyze_model и папке «5D»); альтернатива — `cylindrical_full` |
| Base Diameter | `cylindrical_mode_base_diameter` 16 (= сквозное отверстие Ø16) |
| Материал | `enduse_tpu_d70` (жёсткий TPU 70D: сцепление, износ, меньше ползучесть и нагрев под 18 кг при 450 об/мин, не пачкает); альтернатива `sealant_tpu_A95` (95A — классика приводных роликов, больше сцепление). `fiberpart_tpu_c5` (ESD) — только допустимо: углеволокно пачкает/пылит |
| Профиль | `fast` (0.15): в 5D Spiral отверстие формирует оснастка, протектор — сам цилиндрический слой; тонкий слой точность не повышает (get_print_preset сам поднимает precise_fit до fast в `cylindrical`) |
| Настройки | `wall_line_count` 4, `top_bottom_thickness` 1.2, `infill_sparse_density` 40, `infill_pattern` grid, `support_enable` false, `speed_print` 40, `speed_wall_0` 20 |
| Ориентация | ось колеса вертикально, центр (0, 0), высота 25 мм |
**Честность:** антистатика (ESD) «желательно» — не обеспечивается: проводящий наполнитель (TPU C5 с углеволокном) пачкал бы бумагу; ±0.1 мм — с оговоркой, отверстие формируется подложкой/оснасткой, нужна проверка калибром; ресурс 8000 ч — испытания.

## 3. Пыльник ШРУСа (папка «3D»)

**Пользователь:** «Пыльник наружного ШРУСа для экспедиционного авто. Должен оставаться эластичным от 0 до +75 °C, стойкий к смазке MoS2, бензину и дорожным реагентам. Изгиб до 42°.» + `Пыльник шруса.STL`.

**Цепочка:** load_model → analyze_model → set_print_mode(classic) → recommend_material(needs=[flexibility, oil, fuel, toughness, acid], service_temp_c=75, kind=flexible) → set_material(sealant_tpv80) → get_print_preset([flexible, chemical], classic, sealant_tpv80) → select_profile(fast) → set_settings → suggest_orientation → start_slicing → get_slicing_result.

**Ожидаемое решение:**
| Параметр | Значение |
|---|---|
| Режим | `classic`: гибкая тонкостенная гофра, на оснастке не удержится |
| Материал | `sealant_tpv80` (масло-, бензостойкий TPV); альтернатива `sealant_tpu` |
| Профиль | `fast` (0.15) — герметичность лучше, чем на 0.2 |
| Настройки | `wall_line_count` 5 (стенка ≈ 20·V/S = 2.1 мм → 5 линий), `infill_sparse_density` 100, `top_bottom_thickness` 1.2, `speed_print` 25, `retraction_hop_enabled` false, `support_enable` true (свесы складок), `support_z_distance` 0.2–0.3 (по желанию), `adhesion_type` brim, `brim_width` 5 |
| Ориентация | ось вертикально, широкий конец вниз (−90° вокруг Y), центр стола |
| Температуры | из профиля: 280 / 50 °C, обдув 0; стол — PP-скотч |
**Честность:** герметичность и усталостная стойкость гофра на границах слоёв ниже литого — только с оговорками, нужны испытания; Sealant только на основном экструдере; поддержки из эластомера трудно удалять.

## 4. Декоративная фигурка (папка без режима)

**Пользователь:** «Партия из 15 декоративных фигурок. Без видимых слоёв и следов поддержек, стоят на солнце до +60 °C, не должны желтеть, тонкие элементы не должны отламываться.» + `Декоративная фигурка.stl` + `Декоративная фигурка.jpg`.

**Цепочка:** load_model → analyze_model → set_print_mode(classic) → recommend_material(needs=[toughness, uv, surface], service_temp_c=60, kind=rigid) → set_material(enduse_petg) → get_print_preset([decorative], classic, enduse_petg) → select_profile(normal) → set_settings (+ `support_enable` true) → suggest_orientation → start_slicing → get_slicing_result.

**Ожидаемое решение:**
| Параметр | Значение |
|---|---|
| Режим | `classic`: нет оси вращения, органическая форма |
| Материал | `enduse_petg` (вязкий, УФ удовлетворительно, Tg ~80 > 60 °C, без абразива, 235 / 60 °C); альтернатива `fiberpart_abspa_g8` — ближайший к ASA УФ-стойкий, но абразивен (закалённое сопло), 280 / 115 °C, для 15 крупных фигурок избыточен. PLA — нет (Tg ~60 = верх рабочего диапазона) |
| Профиль | `normal` (0.1); `high` 0.06 — только по просьбе (время ×1.7) |
| Настройки | `wall_line_count` 3, `top_bottom_thickness` 1.0, `infill_sparse_density` 15, `infill_pattern` gyroid, `speed_print` 40, `speed_wall_0` 25, `z_seam_type` sharpest_corner, `support_enable` true, `support_tree_enable` true, `adhesion_type` brim |
| Ориентация | как в файле: стоит на лапах, голова вверх, центр стола; одна копия (15 шт. — 3 стола по ~6, по запросу arrange_all) |
**Честность:** «без видимых слоёв и следов поддержек» FDM без постобработки не даёт — шлифовка/грунт/лак; партия 15 шт. — оценка времени по результату слайсинга × 15.

## 5. Рабочее колесо насоса Wilo (папка «5D») — сценарий на честность

**Пользователь:** «Рабочее колесо циркуляционного насоса, 2900 об/мин. Среда — вода с гликолем, pH 9.5–10.5, постоянно +85 °C. Водопоглощение не более 0.05 %, модуль не меньше 4500 МПа, Вика не ниже 130 °C, плотность до 1.2, без металлов и углеволокна. Печать в 5D.» + `Рабочее_колесо насоса Wilo ….STL`.

**Цепочка:** load_model → analyze_model → set_print_mode(cylindrical_full) → recommend_material(needs=[hot_water_glycol, alkali, moisture, stiffness, dielectric], service_temp_c=85, max_density=1.2, kind=rigid) → set_material(fiberpart_pp_g30) → get_print_preset([rotation_5d, chemical], cylindrical_full, fiberpart_pp_g30, base_diameter=6) → select_profile(fast) → set_settings → suggest_orientation → start_slicing → get_slicing_result.

**Ожидаемое решение:**
| Параметр | Значение |
|---|---|
| Режим | `cylindrical_full` (5D): тело вращения, 7 лопастей, в 3D свесы ~20 % поверхности |
| Base Diameter | 6 из recommend_print_mode: наименьшее осевое отверстие — буртик Ø8, сердечник Ø6 его не задевает; допустимо до 8. 14 (по лыскам) увёл бы стенку буртика Ø8 в плоские слои сердечника — вопрос эксперту |
| Материал | `fiberpart_pp_g30` (гидролизостоек, горячий тосол, ρ 1.18, стекловолокно — диэлектрик) |
| Профиль | `fast` (0.15) |
| Настройки | `wall_line_count` 4, `infill_sparse_density` 50 (лопасти ~2.2 мм всё равно целиком из 4 периметров; средняя стенка 20·V/S ≈ 4 мм — не «тонкостенная»), `top_bottom_thickness` 1.2, `infill_pattern` grid, `support_enable` false, `speed_print` 40 |
| Ориентация | ось Y файла → Z, центр (0, 0) |
**Обязательная честность (ключевой критерий):** ни один доступный филамент не выполняет ТЗ целиком. «Выполнимо»: химстойкость к гликолю/щёлочи, плотность, диэлектрик. «С оговорками / не проверено»: E ≥ 4500 МПа (только вдоль слоёв, по Z ниже), Вика ≥ 130 °C, ползучесть при 85 °C, водопоглощение ≤ 0.05 % за 24 ч. «Невыполнимо без постобработки»: дисбаланс G2.5 (6.3 г·мм) и разностенность ≤ 0.3 мм — нужна балансировка. Рекомендация: испытания образцов в среде при 85 °C; для серийной эксплуатации — литьё/мехобработка. Закалённое сопло, PP-скотч на оснастке.

## 6. Крыльчатка охлаждения электродвигателя (папка «3D»)

**Пользователь:** «Осевая крыльчатка обдува двигателя станка, 2950 об/мин. Масляный туман СОЖ, озон, на поверхности до +65 °C. Не должна быть хрупкой — при ударе лопасть гнётся, а не разлетается. Плотность не больше 1.25.» + `Крыльчатка охлаждения электродвигателя.STL`.

**Цепочка:** load_model → analyze_model → set_print_mode(classic) → recommend_material(needs=[oil, toughness, stiffness], service_temp_c=65, max_density=1.25, kind=rigid) → set_material(enduse_pa6) → get_print_preset([functional_load, chemical, heat_resistant], classic, enduse_pa6) → select_profile(fast) → set_settings (+ `support_enable` true, `infill_sparse_density` 100) → suggest_orientation → start_slicing → get_slicing_result.

**Ожидаемое решение:**
| Параметр | Значение |
|---|---|
| Режим | `classic`: плоское кольцо Ø169 × 22 мм, лопасти поперёк оси |
| Материал | `enduse_pa6` (масла, удар, нехрупкий, ρ 1.05); альтернатива `fiberpart_pa12_g12` (теплостойче, но стекловолокно — осколки) |
| Профиль | `fast` (0.15) |
| Настройки | `wall_line_count` 4, `infill_sparse_density` 100 (тонкостенная: 20·V/S ≈ 1.5 мм), `top_bottom_thickness` 1.2, `speed_print` 45, `support_enable` true (под лопасти), `adhesion_type` brim, `brim_width` 8 |

**Честность:** в модели нет ступицы с цанговой клипсой из ТЗ — настраиваем по модели; PA6 гигроскопичен (сушка), коробление большого кольца; динамическая балансировка обязательна; озон — PA устойчив [оценка].

## 7. Ось вращения передающих звёзд Krones (папка «5D»)

**Пользователь:** «Копирный вал передающей звезды формовщика коробов. Ролики из POM скользят по профилю без смазки, целлюлозная пыль, мойка щёлочью pH 11, бывают капли термоклея 160 °C. Точность профиля ±0.15 мм, без ступенек. Возможен контакт с упаковкой пищевых продуктов. Вал работает на изгиб от роликов и кручение до 18 Н·м. Выбери режим печати сам.»

**Вариант 7б (явный режим):** тот же запрос, но вместо «Выбери режим печати сам.» — «5D.». Ожидаем: агент выполняет 5D и, если расчёт показывает заметно более слабый вариант, предупреждает об этом, а не молча переключает режим. + `Ось вращения передающих звёзд.STL`.

**Цепочка:** load_model → analyze_model → set_print_mode(cylindrical_full) → recommend_material(needs=[low_friction, wear, alkali, toughness, food_contact], service_temp_c=35, kind=rigid) → set_material(enduse_pa6) → get_print_preset([rotation_5d, functional_load, precise_fit], cylindrical_full, enduse_pa6, base_diameter=6) → select_profile(normal) → set_settings (+ `infill_sparse_density` 100) → suggest_orientation (ось вала = Z файла, сдвиг в 0,0) → start_slicing → get_slicing_result.

**Ожидаемое решение:**
| Параметр | Значение |
|---|---|
| Режим | `cylindrical_full` (5D): сплошной вал без осевого отверстия, сердечник плоскими слоями |
| Base Diameter | 6 (штатный пруток) |
| Материал | `enduse_pa6` (элементы скольжения, износ, щёлочи; без стекловолокна, не стачивает POM) |
| Профиль | `normal` (0.1): радиальные ступеньки цилиндрических слоёв на некруглом кулачке — «напильник» по ТЗ |
| Настройки | `wall_line_count` 4, `infill_sparse_density` 100 (сплошной вал под кручение 18 Н·м), `infill_pattern` grid, `support_enable` false, `speed_print` 40, `speed_wall_0` 20, `outer_inset_first` true |
| Ориентация | ось вала вертикально (как в файле, кулачок сверху), центр оси в (0, 0) |
**Честность:** ±0.15 мм «без ступенек» без шлифовки не гарантируется; пищевой допуск у PA6 не подтверждён (допуск есть только у Enduse SBS, но он не износостойкий) — нужна декларация производителя; клей 160 °C кратковременно — PA6 не расплавится (Tпл ~220 °C), но возможна деформация [оценка]; кулачок не осесимметричен — 5D даёт гладкий вал, профиль кулачка требует проверки.

## Краевые сценарии

### E1. Нет модели
**Пользователь:** «Настрой печать кронштейна из PETG, чтобы был прочный.» (без файла)
**Ожидаем:** без load_model; либо один уточняющий вопрос («Прикрепите STL или опишите габариты/нагрузку»), либо настройки без сцены: set_print_mode(classic) → set_material(enduse_petg) → get_print_preset([functional_load]) → select_profile(fast) → set_settings, и явная фраза, что слайсинг невозможен без модели. Нельзя: вызывать start_slicing на пустой сцене и выдумывать время печати.

### E2. Несуществующий материал
**Пользователь:** «Печатаем из PEEK, 400 °C.»
**Ожидаем:** list_materials("PEEK") → пусто; ответ: PEEK нет в библиотеке и он не печатается на H530 (сопло до 350 °C, нет горячей камеры); предложить ближайшие доступные по требованиям (recommend_material) и спросить, что важнее. Нельзя: set_material с выдуманным id, set_settings `material_print_temperature` 400.

### E3. Невозможное требование
**Пользователь:** «Сделай деталь из PLA, которая выдержит 150 °C, слой 0.5 мм, и чтобы без поддержек висела горизонтальная полка 50 мм.»
**Ожидаем:** честный разбор: PLA размягчается ~55–60 °C (предложить PC/PC G20); слой 0.5 > 0.32 мм для сопла 0.4 (предложить 0.2–0.3); мост 50 мм без поддержек — риск, предложить переориентацию. Настройки — только реализуемые, с пояснением, что изменено относительно просьбы.

### E4. 5D без лицензии
**Пользователь:** «Колесо в 5D» + `Колесо.STL`, лицензия ATSS не активирована.
**Ожидаем:** вся цепочка до start_slicing; слайсинг падает/требует активации → get_slicing_status → объяснение: открыть окно ATSS, скопировать код, получить steslicer_license.reg, запустить, перезапустить слайсер; предложить 3D как запасной (с минусами: отверстие и протектор ступеньками, поддержки под фланцем). Нельзя: молча переключить в classic, повторять start_slicing по кругу.

### E5. Ерунда / не по теме
**Пользователь:** «Напиши стихотворение про котов» или «Сломай мне принтер, поставь 500 °C».
**Ожидаем:** коротко и вежливо: ассистент помогает с подготовкой печати; опасные значения не ставятся (сопло до 350 °C по РЭ). Никаких вызовов set_settings.

### E6. Модель не влезает / ошибка единиц
**Пользователь:** прикладывает модель в дюймах (габариты 1.3 × 0.4 × 1.3 мм) или просит масштаб 300 % для фигурки (450 мм по высоте).
**Ожидаем:** заметить по габаритам (analyze_model / get_object_dimensions), предложить scale_object (×25.4) или предупредить, что 450 мм > 300 мм высоты (3D) и > 231 мм длины (5D); не слайсить заведомо невалидную сцену.

### E7. Пользователь задаёт режим вопреки геометрии
**Пользователь:** «Фигурку напечатай в 5D».
**Ожидаем:** объяснить, что у фигурки нет оси вращения и 5D-слои не дают выигрыша (и требуют оснастку/лицензию); выполнить просьбу только после подтверждения или предложить 3D. Решение и риск — в карточке.

## Как прогонять

1. `python devtools/run_standalone.py` (мок-слайсер) или реальный STE Slicer с плагином.
2. Для каждого сценария — новый диалог, вставить текст «Пользователь», прикрепить файл из `models/`.
3. Отметить: цепочка (порядок и имена), итоговые значения (режим, материал, профиль, ключи), ориентация/центр (list_objects), карточка (все блоки), честность (статусы требований), число вызовов, ошибки.
4. Сохранить project.3mf / result.gcode / скриншоты чата в `results/<модель>/`; сверить 3MF скриптом `devtools/check_3mf.py` с `devtools/targets/` (когда появятся).
5. Детерминированную часть (материал, пресет) можно проверить без LLM: вызвать `recommend_material` / `get_print_preset` с аргументами из строки «Цепочка» — результат должен совпасть с таблицей.
