# Модели кейса

В этой папке должны лежать 7 моделей кейса с ТЗ — в репозиторий они не входят. Без них часть тестов пропускается,
а `devtools/pipeline_dryrun.py` и `devtools/live_run.py` не запускаются.

Ожидаемая раскладка (имена папок важны: их используют `devtools/targets/*.json` и тесты):

```
models/
  _TZ_all.txt                                                    тексты всех ТЗ одним файлом
  1. Шестерня - 3D/                                              Шестерня.stl, ТЗ (docx), фото
  2. Колесо конвейерной линии - 5D/                              Колесо.STL, ТЗ, фото
  3. Пыльник Шруса - 3D/                                         Пыльник шруса.STL, ТЗ
  4. Фигурка/                                                    Декоративная фигурка.stl, ТЗ, фото
  5. Рабочее колесо насоса Wilo - 5D/                            STL рабочего колеса, ТЗ
  6. Крыльчатка охлаждения электродвигателя - 3D/                STL крыльчатки, ТЗ
  7. Ось вращения передающих звёзд формовщика коробов Krones - 5D/   STL оси, ТЗ
```

Точные имена STL — в поле `stl` файлов `devtools/targets/*.json`.
